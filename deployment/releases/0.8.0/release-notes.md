# aFolderPlayer 0.8.0

- Упрощены действия перевода: основные кнопки на экране, сравнение и дополнительные действия — в отдельном меню.
- Язык определяется отдельно для каждой песни. Ручной выбор показывает понятные названия языков.
- Добавлено «Перевести заново»: заменяет перевод одной песни после успешного завершения.
- Поиск и перевод продолжаются при повороте экрана; сохраняются текст, позиция чтения и выбранные варианты перевода.
- Сокращены лишние обновления экрана и фоновые записи состояния. Исправлена обработка таймера сна.
- Улучшены организация кода, работа с обложками и сохранение текстов.

Установите aFolderPlayer_0.8.0.apk поверх текущего плеера. Плейлисты и сохранённые тексты сохраняются. Для перевода обновите AFP Translate до 0.3.4; установленные языковые пакеты скачивать заново не нужно.
