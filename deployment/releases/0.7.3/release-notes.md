## Что нового

- Определение песни через микрофон: Меню → Определить песню → Слушать.
- История найденных песен и переход к тексту и переводу.
- Закрытие вложенной настройки возвращает в её меню. Сообщения стали короче.

Для распознавания нужен интернет. Функция экспериментальная: использует неофициальный интерфейс Shazam без оплаты и регистрации; доступность сервиса может меняться. Аудиозапись не сохраняется и не отправляется — передаётся звуковой отпечаток.

Обновляется только плеер. Переводчик и установленные языки остаются прежними.
