## Что нового

- Поиск текста пробует более широкий запрос, если точная запись не найдена. Другие исполнения помечены для проверки.
- Найденные тексты после распознавания остаются на экране.
- Добавлены исправление запроса, поиск в интернете и вставка слов песни.
- Эквалайзер убран из меню опций; основной раздел звука сохранён.
- Отмена и уход с экрана больше не оставляют статус незавершённого поиска.

Для поиска нужен интернет. Наличие текста зависит от базы; дополнительные API не подключены. Поиск в интернете открывает браузер только по нажатию кнопки.

Обновляется только плеер. Переводчик и языковые пакеты остаются прежними.
