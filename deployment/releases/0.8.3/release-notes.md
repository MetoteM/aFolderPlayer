# aFolderPlayer 0.8.3

- Одна проверка обновлений для плеера и расширений перевода: понятные состояния и установка по выбору пользователя.
- Действия с выбранными треками: добавить в плейлист, скрыть от воспроизведения или вернуть, удалить из библиотеки с подтверждением.
- Скрытые треки отмечены в списке и пропускаются при воспроизведении. Удаление из библиотеки сохраняет файлы на устройстве.
- Кнопка обновления библиотеки убрана с основного экрана; обновление доступно через меню.

Установите APK поверх текущей версии. AFP Translate 0.3.5 и установленные языковые пакеты обновлять или скачивать заново не требуется.
