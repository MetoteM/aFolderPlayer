# aFolderPlayer 0.7.1 — китайский офлайн-перевод

- Новый самостоятельный пакет **китайский → русский**, через английский. Обе модели включены; отдельный английский пакет не нужен.
- Переключение установленных языков: **Расширения → Выбрать язык перевода**.
- Китайские предложения без пробелов, длинные строки, абзацы и повтор припева поддерживаются в переводе и сравнении полного текста.
- Ручная установка ZIP выбирает его язык автоматически.
- AFP Translate 0.3.0 сохраняет совместимость с английскими пакетами v1/v2 и сохранённые переводы.

## Установка

Обнови плеер до 0.7.1. В **Расширения → Скачать расширения** установи **AFP Translate 0.3.0**, затем **Китайский → русский · через английский**. Пакет около 227 МБ. После скачивания перевод работает офлайн. На новом телефоне устанавливаются те же три компонента.

## Качество и проверки

Перевод передаёт общий смысл. Промежуточный английский может терять нюансы; рифма и размер не обещаются. Немецкий, французский и испанский запланированы отдельно и в этот релиз не входят.

GitHub Actions успешно проверил реальное Java/ONNX CPU-исполнение, шесть китайских примеров, длинный Unicode-текст без потери символов, отмену, повторы и пустые строки. Прошли 122 теста плеера и 6 тестов движка, включая установку настоящих китайского и английского v2 ZIP; один дополнительный тест старого ZIP v1 пропущен без входного архива. Lint и 11 проверок перенаправлений проходят. Используется сохранённая проверенная сборка, без повторной компиляции.

APK подписаны прежним ключом. Подписи, размеры, SHA-256 и подпись каталога проверяются перед публикацией. Установку и скорость на втором физическом телефоне здесь не проверяли.
