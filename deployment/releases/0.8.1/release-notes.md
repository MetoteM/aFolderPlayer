# aFolderPlayer 0.8.1

- Если перевод фрагмента не завершается, приложение автоматически разбивает его на более короткие части и повторяет попытку.
- Ошибка одного фрагмента больше не скрывает готовый перевод: непереведённые части остаются оригиналом с отметкой.
- «Повторить перевод» продолжает оставшиеся части, сохраняя уже готовые. «Перевести заново» запускает полный перевод.
- Готовый текст остаётся на экране во время повторной попытки.
- Повторные попытки ограничены; одинаковые неудачные фрагменты не обрабатываются заново в одном запросе.

Установите aFolderPlayer_0.8.1.apk поверх текущего плеера и обновите AFP Translate до 0.3.5 для нового режима восстановления. Плейлисты и сохранённые тексты сохраняются. Языковые пакеты скачивать заново не нужно. Для установки новых пакетов используйте раздел расширений плеера; архивы также доступны в [общем наборе моделей](https://github.com/MetoteM/aFolderPlayer/releases/tag/v0.8.0).
