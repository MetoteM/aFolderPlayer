## Что нового

- Определённая песня → «Найти текст» → чтение оригинала. Перевод запускается отдельно, когда нужен.
- Выбранные тексты сохраняются в истории для чтения без интернета.
- Для русского текста перевод находится в дополнительном меню.
- Новый немецкий языковой пакет для перевода на русский. Проверен на «Sonne», «Du hast» и «Steh auf». Перевод приблизительный.

Для немецкого перевода: обнови переводчик до 0.3.1, затем установи немецкий язык через «Расширения → Скачать расширения». Английский и китайский пакеты переустанавливать не нужно.

Дополнительные источники текстов временно заморожены.
