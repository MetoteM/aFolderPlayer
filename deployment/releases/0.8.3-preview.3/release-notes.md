Обновление только AFP Online: плеер и языковые пакеты переустанавливать не нужно.

- Добавлена отдельная кнопка «Проверить музыкальный API отдельно», доступная даже после отказа проверки профиля.
- Ошибки показывают этап запроса: профиль, музыкальный API, поиск, коллекция или поток.
- Успешный ответ музыкального API не считается подтверждением профиля или подписки.

После обновления введите токен своей сессии локально и нажмите «Проверить музыкальный API отдельно». Если запрос пройдёт, можно проверить поиск и выбранный трек.

HTTP 418 самого сервиса не объявляется исправленным. Это раздельная диагностика; реальный доступ ещё предстоит проверить на устройстве. Токен в чат не присылайте.
