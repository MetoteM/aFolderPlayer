# aFolderPlayer 0.8.1 / AFP Translate 0.3.5

Подготовка обновления по обратной связи от 14 октября 2026.

## Состав

- Автоматически восстанавливать незавершённую генерацию конкретного фрагмента: границы предложений/частей предложения, затем слова; китайский текст без пробелов делить по Unicode-символам.
- До трёх уровней дробления, до 14 дополнительных вызовов на строку, бюджет дополнительной работы на документ. Не повторять отмену, ошибки модели, памяти и подключения.
- Сохранять порядок текста и строф. При исчерпании восстановления показывать готовый перевод, оставляя проблемные единицы оригиналом с явной отметкой.
- Не считать частичный перевод полным: основной кэш заменять только полным результатом. Сохранять отдельную контрольную точку готовых единиц; при обычном повторе переводить оставшиеся. «Перевести заново» игнорирует контрольную точку.
- Сохранить протокол старых клиентов; дополнительный метод протокола API 1 с проверкой recoveryVersion передаёт текст и индексы неудачных единиц. Базовая версия API остаётся 1 для совместимости прежних плееров; частичный результат требует AFP Translate 0.3.5.
- Старые языковые пакеты совместимы; веса и движок модели не заменять.
- Проверить ограничения восстановления, отмену, Unicode, неповторение успешных единиц и сборку частичного результата.

## Энергопотребление

Снижение расхода батареи в 0.8.0 не подтверждено измерениями. Ограничения повторов и контрольные точки 0.8.1 предотвращают лишнюю повторную работу, но не дают основания обещать снижение процентов заряда.

Следующий этап: сравнить одинаковую очередь/громкость/выход звука в трёх режимах — воспроизведение при выключенном экране, при открытом плеере без перевода, во время перевода. Учитывать длительность, CPU, wake locks, работу экрана и фоновые задачи. Проверка на эмуляторе не заменяет измерения на устройстве.

## Границы

Обновление опубликовано после проверки кандидата, подписанных файлов и установки на эмуляторе. Оригинальный ключ подписи обязателен. Нового ключа не создавать. Пароль и закрытый ключ не помещать в репозиторий или отчёты.
