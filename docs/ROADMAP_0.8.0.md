# План до 0.8.0

Утверждён 13 октября 2026. Немецкий пакет через английский сохраняется: пользователь подтвердил смысловую пригодность Du hast, Sonne, Mutter. Дополнительные источники текстов отложены.

- 0.7.6: процент и объём скачивания расширений, отдельные состояния проверки/установки; выбор языка для текста без изменения общей настройки; сообщение о конкретном недостающем пакете; возобновляемая подготовка релиза.
- 0.7.7: прямой французский → русский, установка из каталога, проверка качества и памяти.
- 0.7.8: прямой испанский → русский, аналогичные проверки.
- 0.7.9: поиск/удаление истории, позиция чтения, единые состояния действий и навигации.
- 0.8.0: проверка установки с нуля и обновления, регрессия полного пользовательского сценария, публикация полного комплекта.

Каждый этап завершается проверкой и сохранённой контрольной точкой. Нельзя считать релиз готовым до проверки публичного комплекта. Промежуточные публичные релизы необязательны.
