# Хранение файлов сборок

Решение пользователя от 13 октября 2026:

- Исходный код, история Git, теги и опубликованные релизы сохраняются.
- Временные APK проверки и промежуточный комплект публикации — 1 день.
- Отчёты тестов/lint отдельно от APK — 7 дней.
- По запросу пользователя удаляются временные артефакты завершённых запусков.
  Рабочие запуски и журналы workflow сохраняются.
- Подписанные части APK и рецепты восстановления в `deployment/releases`
  остаются частью репозитория; их удаление не входит в очистку Actions.
- Ключ подписи остаётся вне GitHub.

`artifact-maintenance.yml` выполняет эту очистку при добавлении/изменении
своего файла на main либо при явном ручном запуске. Периодического запуска нет.
Обычные новые артефакты удаляются по установленному сроку хранения.
