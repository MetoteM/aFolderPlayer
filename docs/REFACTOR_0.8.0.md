# 0.8.0: аудит, рефакторинг и проверка

Исходная точка: 0.7.9 с патчем языка. Нужные функции и формат сохранений сохраняются.

| Область | Изменения / проверка |
| --- | --- |
| Воспроизведение и очередь | Очередь сохраняется только при изменении timeline, позиция отдельно. Нет периодического сохранения на паузе. Активная позиция каждые 15 с и на событиях/остановке. После внезапного завершения процесса возможна потеря последних 15 с позиции (ранее 2 с). |
| Таймер сна | Отдельный дедлайн вместо проверки каждые 2 с; изменения/отмена перепланируют только этот таймер. |
| Экран плеера | Таймер только при видимом активном воспроизведении; статичные страницы обновляются по событиям. Метаданные и фоны очереди не пересоздаются при обновлении позиции. |
| Тексты/перевод | Общая загрузка SongContent и правила SongTranslationRepository. RetainedOperation хранит задачу без Activity; поиск и перевод не перезапускаются при конфигурационном пересоздании. После уничтожения процесса сохраняются завершённые данные, незавершённая операция не запускается самовольно. |
| Меню | Типизированные действия песни; читаемые названия языков, один английский выбор. Основные действия документа на экране; копирование и сравнение доступны в «Дополнительно». Общий пакет явно относится к документам. |
| Хранение | Совместимые ключи/файлы сохранений. Общий атомарный UTF-8 код для истории и локального текста; защита кеша переводов от одновременной записи. Прежний перевод заменяется только успешным результатом. |
| Изображения/чтение | Обложки в ограниченном кеше 8 МиБ с очисткой при сканировании/нехватке памяти; запись позиции чтения с задержкой 300 мс и сбросом при отсоединении экрана. |
| Переводчик | Отменённые задачи очереди не создают ONNX-сеансы. Декодер, модели, токенизация, качество и ограничения оставлены прежними. |
| Библиотека/плейлисты/поиск | Действующие правила длительности, папок, исключений, очереди, сетевых лимитов и выбора кандидатов сохраняются и проверяются прежними тестами. |
| Определитель | Ограничения локального декодирования, отмена, освобождение MediaCodec/микрофона и отсутствие автоматической отправки аудио сохраняются. Реальный ARM64-декодер требует устройства. |
| Расширения/обновления | Подписи APK/каталога, явная установка, отмена/прогресс и ограничения скачивания сохранены. |
| Весь исходный код | Единое форматирование Java/Kotlin, читаемые блоки/методы. Общие операции вынесены; отдельные приложения сохраняют самостоятельные контракты. |

## Проверки

Сборки, Android unit/regression tests, lint, CPU inference и новые тесты отмены/пересоздания/энергосбережения выполняются для окончательного исходного коммита. Публикация проверяет оригинальную подпись, обновление идентичности, каталог и все публичные файлы.

## Батарея: границы результата

Исправлены конкретные источники лишних таймеров, повторной работы и записей. Изменение фактического расхода батареи в процентах без физического устройства не измерено. Нельзя выдавать количество сокращённых callbacks за процент экономии. Сравнение на устройстве: одинаковые файлы/выход/громкость/яркость, экран выключен/включён, пауза, EQ выкл/вкл и перевод отдельно. Стабильность и звук не жертвуются экономии.
