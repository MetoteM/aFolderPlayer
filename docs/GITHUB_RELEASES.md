# Публикация расширений

Репозиторий: https://github.com/MetoteM/aFolderPlayer

Создать релиз с тегом `extensions-v1`, прикрепить без переименования:
- `catalog.json` из `deployment/public/` — подписанный каталог.
- `AFP_Translate_0.1.0.apk` из поставки 0.5.0.
- `AFP_English_Russian_v1.zip` из поставки 0.4.0.

Каталог содержит размеры и SHA-256 именно этих файлов. Другая сборка с таким же именем не подойдёт.

Обновления расширений публиковать новым тегом и каталогом с увеличенным version, подписанным прежним ключом. Старые релизы сохранять: установленные плееры продолжают использовать их адреса.

Закрытый ключ и signing.properties не публиковать. Автоматические APK без ключа неподписанные. Подпись релизов выполнять прежним ключом локально.

Собственный сервер не требуется; deployment/Caddyfile и compose.yaml — только прежний необязательный вариант.
