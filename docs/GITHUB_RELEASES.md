# GitHub releases

Релиз 0.7.0 содержит `aFolderPlayer_0.7.0.apk`, `AFP_Translate_0.2.0.apk`, `AFP_English_Russian_v2.zip`, `catalog.json` и `SHA256SUMS`.

Рабочие APK подписываются локально прежним закрытым ключом. Ключ и пароль не попадают в репозиторий или GitHub Actions. Для этого выпуска подписанные публичные APK сохранены частями в `deployment/releases/0.7.0/`. Манифест фиксирует имена, размеры, SHA-256 и отпечаток сертификата. Части нужны только для доставки уже подписанных APK в процесс публикации; обычная CI-сборка остаётся неподписанной.

`release.yml` запускается при изменении манифеста на main. Он восстанавливает пакет v2 из проверенных весов extensions-v1 и исправленного токенизатора, запускает сборку, тесты и lint, проверяет подписи и контрольные суммы. Только затем отдельная задача создаёт черновик релиза, загружает все вложения и публикует его как стабильный. Закрытый ключ в CI не используется.

Релизы `v0.6.0` и `extensions-v1` остаются доступны. Повторный запуск не заменяет вложения опубликованного стабильного релиза. Для следующей версии нужны отдельный тег, новый манифест и подписанный каталог; уже опубликованные файлы не изменяются.
