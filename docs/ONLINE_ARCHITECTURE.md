# AFP Online

Необязательное расширение для доступа к Яндекс Музыке. В версии 0.9.0 поддерживаются браузерный вход, коллекция, собственные и добавленные плейлисты, поиск, получение потока и обложек. Проигрывание, очередь, эквалайзер и медиасессия остаются в плеере.

Плеер связывается с сервисом AFP Online по Binder-контракту API 3. Пакет расширения проверяется по подписи; сервис защищён разрешением уровня signature. Данные аккаунта хранятся в расширении, онлайн-метаданные и пользовательские действия — в плеере. Запросы каталога и получения потока используют отдельные очереди, чтобы загрузка плейлиста не блокировала воспроизведение.

Вход выполняется через браузер. LoginSDK не используется. Обычный пакет и экспериментальный .yandexlab имеют раздельные приватные данные. Права аккаунта и ограничения провайдера сохраняются; отсутствие нашей аналитики не исключает обработку запросов сервисом. Пароли и токены не должны попадать в Git или журналы.

## Совместимость каталога расширений

Новый клиент сначала запрашивает подписанный catalog-v2.json (schema 2). Только HTTP 404 разрешает переход к catalog.json. Ошибка подписи, откат версии или другая ошибка ответа не допускает обхода проверки через запасной каталог.

При публикации AFP Online издатель должен формировать и подписывать два каталога: catalog-v2.json со schema 2 и записями engine/model/online; catalog.json со schema 1 только engine/model для старых клиентов. Поля versionName и minimumPlayer описывают версию и минимальный код плеера. Пакеты и подписи APK дополнительно проверяются при установке.

## Исследовательские подключения

Звук остаётся на паузе до ответа о поддерживаемой интеграции. Его исследовательские Activity доступны только в debug и не включены в интерфейс production. Материалы исследования сохранены в ZVUK_INTEGRATION_RESEARCH.md и ZVUK_HTTP418_FINDINGS.md; они не описывают работающую функцию релиза.
