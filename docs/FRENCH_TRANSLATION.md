# Французский → русский: подготовка 0.7.7

Прямой перевод в одну стадию. Английский пакет не требуется.
Плеер: aFolderPlayer 0.7.7, versionCode 33.
Движок: AFP Translate 0.3.2, versionCode 5. API сервиса остаётся 1.

## Модель и пакет

- Базовая модель: https://huggingface.co/Helsinki-NLP/opus-mt-fr-ru
- ONNX: https://huggingface.co/Xenova/opus-mt-fr-ru
- Закреплённая ревизия: `c2ec732b045ae9f0e1ae1ea9267840145a8c03fe`.
- Лицензия Apache 2.0, атрибуция и полная лицензия внутри ZIP.
- Исполнение: прежний `OfflineTranslator`, CPU, квантованные encoder/decoder.
- Токенизатор: исходные SentencePiece scores перенесены в общую таблицу ID;
  элементы только для целевого языка исключены из сегментации источника.
  Padding/start ID 64376, EOS 0, unknown 1.
- ZIP: `AFP_French_Russian_v1.zip`, SHA-256
  `083a0526f9aedb0f6d9abc689bd670c2313afc02aeede57e8a97efe2e1d2ca29`.
- Запись для подписанного каталога: `deployment/french-v1/catalog-entry.json`;
  `minimumEngine: 5` защищает от установки в старый движок 0.3.1.

Воспроизводимая сборка:

```bash
python3 tools/download-french-inputs.py /tmp/french
python3 tools/build-french-package.py /tmp/french /tmp/AFP_French_Russian_v1.zip
```

Каждый скачанный ONNX проверяется по размеру и SHA-256. Сборка ZIP сверяет
реестр движка и ожидаемую запись каталога. Веса не хранятся в исходниках.

## Первая проверка качества и памяти — 13 октября 2026

Production Java decoder на реальных весах, OpenJDK 17, ONNX Runtime 1.20.0,
Linux CPU. Контрольные ID совпали с исходным SentencePiece для апострофов,
акцентов и ligature œ. Пройден тест многострочного текста: пустой абзац,
повторяющийся припев, прогресс одной стадии, отмена, длинные строки.

Результаты контрольных строк:

| Французский | Полученный русский |
| --- | --- |
| Je t'aime. | Я люблю тебя. |
| Ma mère m'a donné une lettre. | Моя мама дала мне письмо. |
| Je la garderai pour toujours. | Я всегда буду держать ее. |
| Ne lâche pas ma main. | Не отпусти мою руку. |
| Nous attendons le lever du soleil. | Мы ждем восхода солнца. |

Смысл в целом сохраняется; местоимения и естественность формулировок требуют
оценки на более широкой выборке. Это приблизительный машинный перевод.
Контрольный запуск с лимитом Java heap 768 МБ: 1.75 с, peak RSS 580328 КиБ
(примерно 567 МиБ, JVM + native memory). Это измерение в Linux, не на телефоне;
скорость и память Honor Magic 7 Pro пока не измерены.
