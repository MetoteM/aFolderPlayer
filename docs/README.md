## Сборка

JDK 17, Android SDK 36, Gradle Wrapper 8.11.1.

```sh
./gradlew :app:assembleRelease :translator:assembleRelease :online:assembleRelease :app:testReleaseUnitTest :translator:testReleaseUnitTest :online:testReleaseUnitTest :app:lintRelease :translator:lintRelease :online:lintRelease
```

Без локального ключа создаются неподписанные APK. Для обновления установленного приложения нужен прежний ключ. Закрытый ключ не хранится в Git и не передаётся в Actions.

## Приёмочные проверки

### Поиск текста песни

Отсчитывайте 60 секунд с момента запуска поиска. Если до истечения минуты
получен текст или приложение вернуло окончательный статус, зафиксируйте
фактический результат и оцените его по ожидаемому результату сценария.
Если к концу минуты поиск ещё идёт, зафиксируйте «Тайм-аут (60 с)»,
прекратите ожидание и сразу переходите к следующему тесту. Поздний ответ
не меняет зафиксированный результат прогона.

### Ошибка онлайн-потока

Запустите онлайн-очередь из нескольких треков и воспроизведите первый.
Вызовите окончательную ошибку загрузки его потока. Плеер должен сам начать
следующий трек с начала. При перемешивании действует порядок воспроизведения.
Если потоки всей очереди недоступны, повтор очереди не должен приводить
к бесконечным переключениям.
