# 0.8.3 — обновления и основа онлайн-раздела

- Одна кнопка «Проверить обновления»: плеер, установленные расширения и языковые пакеты.
- Раздельные состояния: актуально, доступно, необходимо для совместимости, необязательно, не удалось проверить.
- Установка каждого APK только после подтверждения пользователя; проверяются подпись, пакет, версия, размер и SHA-256. Отмена Android-установки не означает успешную установку.
- После подтверждённого изменения установленной версии повторяется общая проверка зависимостей.
- Для восстановления незавершённого перевода требуется AFP Translate 0.3.5/code 8 или новее.
- Уже установленные неизменяемые языковые пакеты не скачиваются повторно. Новая редакция языка — отдельное предложение.
- AFP Online — отдельный необязательный APK. Реестр коннекторов, первым Звук; Яндекс отложен.
- В этой подготовке нет работающего входа или воспроизведения Звука. Следующий этап — проверить доступный способ авторизации и потокового воспроизведения с подпиской, затем реализовать коннектор.
- Экран проигрывателя не расширяется. Фоновый опрос обновлений не добавлен.

Проверки: модульные тесты планирования и подписанного каталога, сценарий общей проверки через UI, сборка и lint всех трёх модулей в GitHub Actions. Статус выполнения смотреть в проверках PR; этот документ не является утверждением об их успешном завершении.
