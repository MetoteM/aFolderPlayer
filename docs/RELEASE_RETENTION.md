# Хранение выпусков

Приоритет для пользователей — последний стабильный релиз и предыдущий стабильный.
Старые версии не следует удалять автоматически по номеру или возрасту.

Обязательные источники текущего комплекта:

- v0.8.0: английский, китайский, немецкий, французский и испанский пакеты.
- v0.9.11: исходные APK для восстановления опубликованных 0.9.12 и переводчика 0.3.6.
- v0.9.12: итальянский пакет, предыдущий стабильный плеер и основа 0.9.13.
- extensions-v1 и v0.7.0: совместимость прежних каталогов и сценариев установки моделей.

Исторические manifests и workflows также ссылаются на v0.7.4, v0.7.6,
v0.7.7, v0.7.9, v0.8.1 и v0.8.2. Их удаление может нарушить восстановление
соответствующих старых сборок даже при работоспособности текущего приложения.

Кандидаты на отдельное согласованное удаление: v0.5.2, v0.6.0,
v0.8.3-preview.1, v0.8.3-preview.2, v0.8.3-preview.3, v0.9.5-hotfix4.
Перед удалением проверить внешние ссылки и сохранить необходимые файлы.
В рамках выпуска 0.9.13 ничего не удаляется; обновляются пользовательские тексты.

Удаление GitHub Release не уменьшает историю Git с ранее добавленными бинарными
частями. Очистка этой истории — отдельная задача, без автоматического force-push.
