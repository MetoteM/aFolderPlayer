# Версии aFolderPlayer

С выпуска 0.4.0 используем MAJOR.MINOR.PATCH:
- PATCH: исправления без новых функций — 0.4.1, 0.4.2.
- MINOR: новые совместимые функции — 0.5.0, 0.6.0; PATCH сбрасывается.
- MAJOR: крупные несовместимые изменения — 1.0.0, 2.0.0; MINOR и PATCH сбрасываются.

Android versionCode увеличивается при каждой поставке независимо от номера версии. 0.4.0 — versionCode 21. applicationId и ключ подписи сохраняются. Миграции пользовательских данных проверяются отдельно.

0.5.0 — versionCode22, совместимое разделение движка и плеера. AFP Translate имеет отдельную версию0.1.0 / versionCode1 и протокол1.
