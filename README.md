# aFolderPlayer

Android-плеер с библиотекой по папкам, плейлистами и необязательным подключением Яндекс Музыки.

**Версия 0.9.13** · [Скачать APK](https://github.com/MetoteM/aFolderPlayer/releases/latest) · [Что нового](CHANGELOG.md)

## Возможности

- Аудиокниги: папка с главами или один файл, отдельная позиция, скорость, закладки и таймер сна.
- Локальные MP3 и FLAC, папки и подпапки, поиск, плейлисты и очередь.
- Фоновое воспроизведение, эквалайзер, управление с гарнитуры и часов.
- Выбор нескольких треков: добавить в плейлист, скрыть от воспроизведения или исключить из библиотеки без удаления файлов.
- Поиск и сохранение текстов, распознавание музыки по запросу.
- Офлайн-перевод на русский с английского, немецкого, французского, испанского, итальянского и китайского.
- Яндекс Музыка через AFP Online: коллекция, плейлисты, поиск и воспроизведение в общем плеере, ссылки на треки, настройки сети и качества.

## Установка и обновление

Установите APK плеера поверх текущей версии, без удаления приложения. Библиотека, плейлисты и настройки сохраняются. Проверка обновлений доступна через «О приложении → Проверить обновления».

Для Яндекс Музыки установите **AFP Online 0.2.2** из того же релиза и войдите через браузер. Возможности сервиса зависят от аккаунта и подписки. AFP Online необязателен для локальной музыки.

Для перевода нужны **AFP Translate 0.3.6** и выбранные языковые пакеты. Их можно установить через раздел расширений. При обновлении с 0.9.12 расширения и языковые пакеты переустанавливать не требуется. Итальянский пакет переводит через английский; обе модели включены. Если язык песни не определён, выберите его вручную.

## Аудиокниги

Откройте «Настройки → Аудиокниги» и добавьте папку книги или отдельный аудиофайл. Главы из папки идут в порядке имён файлов. Позиция и скорость сохраняются отдельно для каждой книги; закладки доступны на экране книги. Удержание книги открывает обновление файлов и удаление из списка без удаления аудиофайлов.

Длинный M4B поддерживается как один файл. Встроенное оглавление M4B пока не отображается.

## Сеть и приватность

Собственной рекламы и аналитики нет. Локальная музыка и установленный перевод работают офлайн. Поиск текстов и распознавание запускаются по запросу. При распознавании передаётся звуковой отпечаток; локальные аудиофайлы не загружаются.

Онлайн-сервис получает запросы авторизации, каталога и аудиопотоков; при проигрывании обложки и музыка загружаются с его серверов. Экспериментальное сохранение MP3 запускается вручную с выбором места сохранения.
