# aFolderPlayer

Минималистичный Android-плеер для выбранных папок и подпапок: локальная библиотека, плейлисты, фоновое воспроизведение, эквалайзер и управление через медиасессию.

Версия **0.7.0**. [Стабильные релизы и APK](https://github.com/MetoteM/aFolderPlayer/releases).

## Перевод

Плеер не содержит движок перевода. AFP Translate и языковой пакет устанавливаются отдельно по выбору пользователя. Перевод выполняется офлайн; движок не имеет разрешения INTERNET. Сейчас поддерживается английский → русский.

На экране «Перевод» кнопка «Полный текст · сравнение и история» открывает сравнение переводов по абзацам и предложениям. Можно выбрать вариант для каждого фрагмента, сохранить полный результат и скопировать его. Повторяющиеся части сохраняются при сборке. Предупреждения о возможных пропусках не заменяют проверку смысла. Перевод не синхронизирован с метками LRC.

AFP Translate 0.2.0 поддерживает прежний пакет v1 и пакет v2 с исправленным токенизатором. Они имеют отдельные идентификаторы и кэши. При установке v2 старый пакет не удаляется. История лаборатории хранится в отдельном приложении и автоматически не переносится.

## Расширения

Источник по умолчанию: GitHub Releases этого репозитория, тег `v0.7.0`. Пакеты предыдущего релиза `extensions-v1` остаются доступны. Скачивание разрешено только по HTTPS; перенаправления GitHub ограничены серверами файлов GitHub. Подпись каталога, размер, SHA-256 и подпись APK проверяются.

Запросов в фоне, рекламы и аналитических SDK нет. Хостинг технически видит IP при скачивании. Поиск текстов и годов альбомов выполняется по действию пользователя; аудиофайлы не отправляются.

## Сборка

JDK 17, Android SDK 36, Gradle Wrapper 8.11.1.

```sh
./gradlew :app:assembleRelease :translator:assembleRelease :app:testReleaseUnitTest :translator:testReleaseUnitTest :app:lintRelease :translator:lintRelease
```

Без закрытого ключа создаются неподписанные release APK. Они не подходят для установки поверх опубликованного приложения. Для подписания нужен прежний ключ в локальной папке `signing/`, которая исключена из Git. Проверки GitHub Actions не используют закрытый ключ.
