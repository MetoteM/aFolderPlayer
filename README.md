# aFolderPlayer

Минималистичный Android-плеер для выбранных папок и подпапок: локальная библиотека, плейлисты, фоновое воспроизведение, эквалайзер и управление через медиасессию.

Версия **0.8.1**. [Стабильные релизы и APK](https://github.com/MetoteM/aFolderPlayer/releases).

## Перевод

Плеер не содержит движок перевода. AFP Translate и языковой пакет устанавливаются отдельно по выбору пользователя. Перевод выполняется офлайн; движок не имеет разрешения INTERNET. Поддерживаются английский, немецкий, французский, испанский и китайский → русский. Для каждой песни автоматически выбирается подходящий установленный пакет независимо от общей настройки.

На экране «Перевод» меню «Дополнительно → Сравнение и история» открывает полный перевод; в его дополнительном меню доступны сравнение переводов по абзацам и предложениям и проверка возможных пропусков. Можно выбрать вариант для каждого фрагмента, сохранить полный результат и скопировать его. Повторяющиеся части сохраняются при сборке. Предупреждения о возможных пропусках не заменяют проверку смысла. Перевод не синхронизирован с метками LRC.

AFP Translate 0.3.5 поддерживает все пять языков, прежний английский пакет v1 и пакет v2 с исправленным токенизатором. Они имеют отдельные идентификаторы и кэши. При установке v2 старый пакет не удаляется. История лаборатории хранится в отдельном приложении и автоматически не переносится.

## Расширения

Источник по умолчанию: последний стабильный релиз GitHub этого репозитория. Неизменившиеся модели скачиваются по подписанным ссылкам из общего набора `v0.8.0`, без дублирования архивов в новых релизах. Пакеты предыдущего релиза `extensions-v1` остаются доступны. Скачивание разрешено только по HTTPS; перенаправления GitHub ограничены серверами файлов GitHub. Подпись каталога, размер, SHA-256 и подпись APK проверяются.

Запросов в фоне, рекламы и аналитических SDK нет. Хостинг технически видит IP при скачивании. Поиск текстов и годов альбомов выполняется по действию пользователя; аудиофайлы не отправляются.

## Сборка

JDK 17, Android SDK 36, Gradle Wrapper 8.11.1.

```sh
./gradlew :app:assembleRelease :translator:assembleRelease :app:testReleaseUnitTest :translator:testReleaseUnitTest :app:lintRelease :translator:lintRelease
```

Без закрытого ключа создаются неподписанные release APK. Они не подходят для установки поверх опубликованного приложения. Для подписания нужен прежний ключ в локальной папке `signing/`, которая исключена из Git. Проверки GitHub Actions не используют закрытый ключ.

## Лицензии зависимостей

AndroidX / Media3 — Apache-2.0; ONNX Runtime — MIT; OPUS-MT en-ru — Apache-2.0. Тексты лицензий включены в соответствующие модули и пакеты. Лицензия на сам проект отдельно не объявлена.

Публикация расширений: [инструкция](docs/GITHUB_RELEASES.md).

Проверка обновлений: меню → О приложении → Проверить обновления. Запросы только по кнопке. Устанавливается APK стабильного релиза с совпадающей подписью и большим versionCode; размер и SHA-256 также проверяются.

Китайский → русский: отдельный пакет с двумя моделями (через английский), около 227 МБ. Перевод офлайн, общий смысл. Установленные языки переключаются в расширениях. Немецкий, французский и испанский запланированы отдельно.

В 0.7.2 обычный перевод использует тот же контекст предложений, что и полный текст: переносы внутри фразы объединяются, куплеты и повторы сохраняются. Обновлять движок 0.3.0 и языковые пакеты для исправления не требуется.

## Распознавание музыки

Кнопка «Определить песню» в библиотеке или на экране плеера → Слушать. Запись через микрофон до 30 секунд, определение через интернет, история последних 50 результатов. Из результата можно найти текст и открыть перевод. Запись не сохраняется: отправляется только звуковой отпечаток, без геолокации. Микрофон отключается при отмене и уходе с экрана. Интерфейс Shazam неофициальный, без ключа и оплаты на момент проверки; доступность не гарантирована. Алгоритм адаптирован из ShazamIO 0.4.0.0 (MIT). Реальные запросы проверены на тестовом аудио; микрофон физического телефона требует проверки.

Вложенные настройки сохраняют родительское меню. Сведения о сервисах и лицензиях доступны через «О приложении → Подробнее».

В 0.7.4 поиск текста при отсутствии точной записи расширяет запрос до названия песни. Другие исполнители показаны отдельно для проверки пользователем. Поддерживаются кириллица, ё/е и удаление служебных пометок. Дополнительные открытые API проверены, но не подключены: на контрольных примерах они не дали подходящих результатов. Поиск в интернете открывает браузер только по кнопке; найденный текст можно вставить самостоятельно.

В 0.7.5 выбранный текст открывается для чтения и автоматически сохраняется для офлайн-доступа из истории распознавания. Перевод запускается только отдельной кнопкой. Немецкий пакет автономен (de→en→ru); нужен переводчик 0.3.1. Дополнительные источники текстов заморожены.

В 0.8.0 поиск и перевод сохраняются при повороте экрана, добавлено безопасное повторное выполнение перевода одной песни, упрощены дополнительные меню. Сокращены лишние фоновые обновления и записи состояния; измерение экономии батареи на физическом устройстве выполняется отдельно.

В 0.8.1 незавершённый перевод автоматически повторяется после дробления проблемного фрагмента. Готовые части сохраняются, а обычный повтор продолжает оставшиеся. Для восстановления нужен AFP Translate 0.3.5; установленные модели сохраняются.
